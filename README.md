# Raven for OpenAI

Connect your Raven account to search its proprietary research library and run investment research. The package connects the existing remote MCP server without a tool filter. Available tools follow your account permissions and enabled modules.

Upload the ZIP at https://platform.openai.com/plugins. Connect the MCP server, complete Raven OAuth, and enable the desired modules in the Raven console. Do not paste cookies, API keys, or bearer tokens.

Before submitting for review, inspect the discovered tool list, verify all intended modules, and run real tool calls. A successful upload alone does not verify OAuth or tool behavior.
